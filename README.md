# PokeHub

Aplicação web interativa desenvolvida em **React.js** que consome dados da **PokéAPI**, realizada no âmbito da unidade curricular de **Tecnologias Web** (CTeSP em Desenvolvimento de Software - ESAN, Universidade de Aveiro).

## 📋 Sobre o Projeto
O **PokeHub** é uma plataforma web desenhada para reunir e explorar o universo Pokémon num só lugar de forma intuitiva e visual. Através da integração com a **PokéAPI**, os utilizadores podem consultar informações detalhadas sobre as criaturas, analisar vantagens e fraquezas elementais e navegar pelas diferentes regiões e gerações.

## ✨ Funcionalidades Principais
* **Início:** Página principal com acesso rápido às diferentes áreas da plataforma.
* **Pokédex:** Listagem e consulta detalhada de todos os Pokémon e das suas características.
* **Pesquisa Rápida:** Barra de pesquisa integrada no cabeçalho para encontrar Pokémon diretamente pelo nome ou número.
* **Tipos:** Exploração das vantagens e fraquezas associadas a cada tipo elemental.
* **Regiões:** Navegação pelas diferentes regiões e respetivas gerações do mundo Pokémon.
* **Sobre a API:** Secção informativa sobre o funcionamento da PokéAPI e a forma como os dados são obtidos.

## 🚀 Tecnologias e Ferramentas Utilizadas
* **React.js** (Componentes funcionais, Props, Hooks `useState` e `useEffect`)
* **Vite** (Ambiente de desenvolvimento e build)
* **React Router** (Configuração de rotas para Início, Pokédex, Tipos, Regiões e Sobre a API)
* **PokéAPI** (Consumo de dados em formato JSON via REST API)
* **CSS**

## ⚙️ Como Executar o Projeto Localmente

1. **Clonar o repositório:**
   ```bash
   git clone https://github.com/utilizador/pokehub.git
   ```

2. **Aceder à pasta do projeto:**
   ```bash
   cd pokehub
   ```

3. **Instalar as dependências:**
   ```bash
   npm install
   ```

4. **Iniciar o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```
   A aplicação ficará acessível no browser através do endereço indicado no terminal (normalmente `http://localhost:5173`).
