# PokeHub

Aplicação web interativa desenvolvida em **React.js** que consome dados da **PokéAPI**, realizada no âmbito da unidade curricular de **Tecnologias Web** (CTeSP em Desenvolvimento de Software - ESAN, Universidade de Aveiro)[cite: 1, 3].

## 📋 Sobre o Projeto
O **PokeHub** é uma plataforma web desenhada para reunir e explorar o universo Pokémon num só lugar de forma intuitiva e visual[cite: 3]. Através da integração com a **PokéAPI**, os utilizadores podem consultar informações detalhadas sobre as criaturas, analisar vantagens e fraquezas elementais e navegar pelas diferentes regiões e gerações[cite: 3].

## ✨ Funcionalidades Principais
* **Início:** Página principal com acesso rápido às diferentes áreas da plataforma[cite: 3].
* **Pokédex:** Listagem e consulta detalhada de todos os Pokémon e das suas características[cite: 3].
* **Pesquisa Rápida:** Barra de pesquisa integrada no cabeçalho para encontrar Pokémon diretamente pelo nome ou número[cite: 3].
* **Tipos:** Exploração das vantagens e fraquezas associadas a cada tipo elemental[cite: 3].
* **Regiões:** Navegação pelas diferentes regiões e respetivas gerações do mundo Pokémon[cite: 3].
* **Sobre a API:** Secção informativa sobre o funcionamento da PokéAPI e a forma como os dados são obtidos[cite: 3].

## 🚀 Tecnologias e Ferramentas Utilizadas
* **React.js** (Componentes funcionais, Props, Hooks `useState` e `useEffect`)
* **Vite** (Ambiente de desenvolvimento e build)
* **React Router** (Configuração de rotas para Início, Pokédex, Tipos, Regiões e Sobre a API)[cite: 1, 3]
* **PokéAPI** (Consumo de dados em formato JSON via REST API)[cite: 1, 3]
* **CSS / [Bootstrap]**
